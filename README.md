# Tom Sanson | Portfolio Website

A personal portfolio website built to showcase who I am, what I'm learning, and the projects I'm building. Crafted with curiosity and code.

## About

I'm a Computer Science Engineering student passionate about technology, programming, and building things that solve real-world problems. This site is my space to share my story, skills, and ways to get in touch.

## Features

- Clean, responsive layout that works on desktop and mobile
- Dark theme with a light/dark mode toggle
- Navigation bar with quick links to every section
- Dedicated pages for About, Skills, and Contact
- Custom logo and profile photo

## Pages

| Page | Description |
| --- | --- |
| Home | Introduction and overview |
| About | A bit more about me |
| Skills | Skills I have and the ones I'm currently learning |
| Contact | Social media handles and contact information |
